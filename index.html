Competition time ends after two complete runs or two incomplete runs, or when the 8-minute limit is reached. Therefore a team can have up to three counted runs (for example, Complete → Incomplete → Complete).
Official scoring formulas implemented

Final Score = Best Run Score. Run Score = DS + TS + MS.

Distance Score: Complete DS = 40. Incomplete DS = 40 × (185 − distance from finish in cm) / 185. If ramp is used, DS × 0.5.

Time Score: Complete TS = 40 × (1 − |Runtime − TT| / TT), with minimum TS = 0. Incomplete TS = 0.

Mass Score: MS = (4R + 0.1N) × (185 − distance from finish in cm) / 185. Half roll counts as R = 0.5. Complete-run maximum MS = 20. Ramp MS = 0.

Penalties: missed impound ×0.70; each construction violation ×0.80; each competition violation ×0.90, applied to DS, TS and MS.

Touch/interference: counted as a complete run with DS = TS = MS = 0.

No-start case: if the dowel does not cross the start line within 3 seconds of launch, it does not count as a run and should not be saved here.
